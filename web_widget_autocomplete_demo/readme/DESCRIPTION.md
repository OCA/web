This module is a **demo** of the autocomplete Char widget
(`web_widget_autocomplete`) on the partner **City** field.

Suggestions are an in-memory list of cities with ZIP codes: Umbria and
other well-known Italian cities first, plus a few famous world cities.
Focusing **City** shows the first five cities before any typing.
Selecting a suggestion fills **City** and **ZIP**. There is no HTTP
lookup.
