This module provides a resource-based calendar view for Odoo using the DayPilot Lite library. It serves as a drop-in replacement for Gantt views, offering a modern scheduling interface with resources displayed as columns and time slots on the vertical axis.

Key features include:
- Resource-based calendar view (resources as columns, time on vertical axis)
- Drag-and-drop event moving and resizing
- Time slot selection for creating new events
- Configurable business hours and time slot duration
- Business-hours-only display toggle
- Integration with Odoo's standard view architecture
- Dark mode support
- LGPL-3 licensed (open source and commercial-friendly)
