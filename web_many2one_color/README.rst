This module colors the selected value of many2one (selection) fields
depending on a color state stored on the target record.

A record can be flagged as *Warning* (yellow) or *Critical* (red),
together with an optional message. Every many2one field pointing to that
record then shows its name in that color, in edit mode as well as in
read-only list and kanban cells. The message is displayed as tooltip,
and matching entries in the autocomplete dropdown are colored too.

This module only provides the mechanism: the abstract model
``many2one.color.mixin`` with the two fields, the session information
telling the web client which models provide it, and the widget patches.
Install an implementation module such as ``partner_many2one_color``
(contacts) to use it, or inherit the mixin on your own model.

Configuration
=============

The coloring is active by default on every many2one field pointing to a
model that provides the color state. To disable it on a specific field,
add the ``no_color`` widget option in the view:

.. code:: xml

   <field name="partner_id" options="{'no_color': True}" />

The option applies to the field node it is set on. When the same field
is shown several times in a view, the color data is read once for all of
its nodes and only the nodes without the option are colored.

Usage
=====

To make the records of a model colorable, inherit the mixin and expose
the fields ``many2one_color`` and ``many2one_color_message`` in its form
view:

.. code:: python

   class MyModel(models.Model):
       _name = "my.model"
       _inherit = ["my.model", "many2one.color.mixin"]

The color fields are read as sub-fields of the many2one value with the
access rights of the current user, so the mixin is meant for models that
backend users can read. Records the user cannot read are shown without
color.

The ``no_color`` option is honored for the fetching of the color data on
every many2one widget. Specialized widgets that build their own
properties (for example ``many2one_avatar``) still color the dropdown
entries while a record is being searched.
