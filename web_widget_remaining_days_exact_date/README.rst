Usage
=====

Go to Settings > Technical > User Interface > Disable Remaining Days Rules and create a new record with the model,
view type or field you want to disable the remaining days widget.
    - The widget is disabled in the full model if no view type or field is selected.
    - The widget is disabled in the view type if no field is selected.
    - The widget is disabled in the date or datetime field if it is selected.
