This module adds a ``markdown`` widget for text fields, based on `Toast
UI Editor <https://ui.toast.com/tui-editor>`__ (MIT license, actively
maintained).

- Markdown and WYSIWYG editing modes, with live preview
- Toolbar: headings, emphasis, lists, task lists, tables, images, links,
  code
- Read-only fields are rendered as HTML by the Toast UI viewer
- The field stores the raw Markdown text

To paste Markdown into regular HTML fields, see the module
``web_editor_paste_markdown``.

.. IMPORTANT::
   This is an alpha version, the data model and design can change at any time without warning.
   Only for development or testing purpose, do not use in production.
   `More details on development status <https://odoo-community.org/page/development-status>`_

Use Cases / Context
===================

Odoo 16 has no Markdown widget, and the OCA module
``web_widget_text_markdown`` is not available for 16.0 and relies on the
unmaintained bootstrap-markdown library.

Configuration
=============

No configuration is required.

Usage
=====

Add the ``markdown`` widget to a text field in a form view:

.. code:: xml

   <field name="description" widget="markdown" />

Options, passed through the ``options`` attribute:

.. code:: xml

   <field
     name="description"
     widget="markdown"
     options="{'height': '500px', 'initial_edit_type': 'wysiwyg'}"
   />

+-----------------------+----------------+-----------------------------+
| Option                | Default        | Description                 |
+=======================+================+=============================+
| ``height``            | ``"auto"``     | editor height               |
+-----------------------+----------------+-----------------------------+
| ``min_height``        | ``"200px"``    | minimum editor height       |
+-----------------------+----------------+-----------------------------+
| ``initial_edit_type`` | ``"markdown"`` | initial mode:               |
|                       |                | ``"markdown"`` or           |
|                       |                | ``"wysiwyg"``               |
+-----------------------+----------------+-----------------------------+
| ``hide_mode_switch``  | ``false``      | hide the Markdown / WYSIWYG |
|                       |                | switch                      |
+-----------------------+----------------+-----------------------------+
| ``placeholder``       | ``""``         | placeholder of the empty    |
|                       |                | editor                      |
+-----------------------+----------------+-----------------------------+
| ``language``          | -              | Toast UI language code      |
|                       |                | (e.g. ``"fr-FR"``)          |
+-----------------------+----------------+-----------------------------+

The field stores the raw Markdown text. The widget is not available on
html fields: Odoo sanitizes them on save, which would alter the
Markdown. To insert Markdown in an html field, see the module
``web_editor_paste_markdown``.

The editor opens in Markdown mode; the tabs below the editor switch
between Markdown and WYSIWYG. In WYSIWYG mode, use the toolbar for
headings and lists: Markdown signs typed there are kept as plain text.

With demo data, open Settings > Users & Companies > Groups > Markdown
widget demo, tab Notes.

Development
===========

The widget is the OWL component ``MarkdownField``
(``static/src/js/markdown_field.esm.js``), registered as ``markdown`` in
the ``fields`` registry. It mounts a Toast UI editor in edit mode and a
Toast UI viewer in read-only mode, and commits the Markdown on blur and
before the record is saved.

Tests: QUnit suite ``web_widget_markdown_editor``, run by
``tests/test_js.py``.

Known issues / Roadmap
======================

- The widget stores Markdown in text fields: rendering such a field
  elsewhere (for example in a report) needs a conversion to HTML.
- An html mode could load and save HTML through Toast UI (``setHTML`` /
  ``getHTML``), so that html fields can be edited in Markdown. Toast UI
  only keeps Markdown-compatible HTML: colors, styles and Odoo classes
  of existing content would be lost.
- Toast UI Editor is shipped minified in ``static/src/lib`` (version
  3.2.2).
- The preview is always shown as a tab: the ``preview_style`` option is
  read but not applied yet.
