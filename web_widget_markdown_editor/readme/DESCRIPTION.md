This module adds a `markdown` widget for text fields, based on
[Toast UI Editor](https://ui.toast.com/tui-editor) (MIT license, actively maintained).

- Markdown and WYSIWYG editing modes, with live preview
- Toolbar: headings, emphasis, lists, task lists, tables, images, links, code
- Read-only fields are rendered as HTML by the Toast UI viewer
- The field stores the raw Markdown text

To paste Markdown into regular HTML fields, see the module `web_editor_paste_markdown`.
