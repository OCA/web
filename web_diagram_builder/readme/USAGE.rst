Go to **Diagrams** in the top menu (or navigate to the module directly).

1. Click **New** to create a diagram.
2. Give it a name.
3. In **Data Source**, select a **Model** (e.g. *Contact*) and a **Parent
   Field** (e.g. *Company*).
4. Optionally set a **Filter Domain** to limit the records displayed.
5. Click **Generate Diagram**.
6. Click **View Diagram** to open the interactive diagram.

In the diagram view:

* **Scroll** to zoom in/out.
* **Drag** nodes to reposition them.
* Click **Export PNG** to download a full-resolution image.
* Click **Help** for navigation tips.

Use **Find Path Between Two Nodes** on the form to highlight the shortest
path between any two nodes in the hierarchy.
