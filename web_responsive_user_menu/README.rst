This module keeps the backend top bar focused on essential information
by removing the technical app-menu preferences icon from the systray.

The app-menu preferences remain available from the user menu, where they
are less intrusive and easier to discover as a user preference. The
module uses the existing preferences action provided by
``web_responsive`` and does not modify that module.
