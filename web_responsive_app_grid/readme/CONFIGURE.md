No server-side configuration is needed.

Each user's layout is stored in their user settings. From the app's **More /
Options** link (edit mode), the *App Menu Preferences* dialog offers a
**Reset layout** button that clears the arrangement and rebuilds the grid in
the default menu order.

While this module is installed, the `web_responsive` tint/preferences systray
icon is hidden (the same preferences open from the grid's Options link).
