This module turns the `web_responsive` app drawer into a phone-like home
screen.

App icons live on a free-form grid (6 columns, 4 on narrow screens) and can
be arranged anywhere, just like on an iPhone or Android home screen. Icons
can be grouped into sections separated by horizontal rules with optional
titles.

The arrangement is stored per user, so every user can organize their own
home screen, and it survives resizes: positions are kept per row and
column, so shrinking the window only wraps the rightmost icons onto an
extra row inside their group.
