Open the app drawer (the grid button in the navbar, or the Home key).

- Click an app to open it.
- **Long-press** anywhere on the grid (~0.5s) to enter edit mode — or press
  and hold an icon and start dragging in the same gesture.
- Drag an icon onto an empty cell to move it. Drag onto another icon — the
  apps shift right (wrapping to the next row) to open the slot, and a faded
  copy of the dragged icon shows where it will land.
- Drop near a row's **top or bottom edge** — a dashed horizontal line shows
  where a group boundary will be created. Drop on an icon's **left/right
  edge** to split a group at that point.
- Groups show a horizontal separator. Double-click it to type a name;
  the × removes the boundary. Drag the separator itself to reorder groups.
- **Save** exits edit mode and persists; **Discard** undoes the last change
  (multiple steps); **+ Group** adds an empty group; **Options** opens the
  per-user App Menu Preferences, including a **Reset layout** button that
  restores the default order. Escape also exits edit mode.
