1. Go to any view with a search bar (e.g. a list or kanban view).
2. Uncheck the "Auto search" checkbox displayed next to the search bar.
3. Add or remove as many filters, group by, or favorites as you need:
   the view is not refreshed automatically anymore.
4. Click the search icon to run the search with all the selected
   filters at once.
5. Check "Auto search" again to go back to the default behavior.
