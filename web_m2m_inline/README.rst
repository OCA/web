This module extends the functionality of the Many2Many field in Odoo to
support inline adjustments. It allows users to directly add or edit
Many2Many field values within the form view.

**Table of contents**

.. contents::
   :local:

Usage
=====

To use this module, you need to add widget="m2m_inline":

.. code:: XML

   <field name="my_m2m_field_ids" widget="m2m_inline">
        <tree editable="bottom">
          <field name="name"/>
        </tree>
   </field>

There is an OOTB option to allow quick unlinking record:

.. code:: XML

   <field name="my_m2m_field_ids" widget="m2m_inline" options="{'quick_unlink': True}">
        <tree editable="bottom">
          <field name="name"/>
        </tree>
   </field>

Known issues / Roadmap
======================

There is a bug with updating existing records: if a user clicks on
existing rows and makes changes, then discards those changes and
subsequently clicks to add a new record, the existing records get
updated incorrectly.
