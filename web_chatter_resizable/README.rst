This module lets users resize the chatter shown on the side of a view by
dragging its edge, so that long messages and logged details are easier
to read.

The handle is available on every side chatter: in form views and in any
other view that shows the standard chatter on the side, e.g. the bank
reconciliation of Odoo Enterprise. It is not shown when the chatter is
below the view.

The width is kept in the browser of each user, one width per kind of
view (form, kanban...). Beside a side chatter, the form uses all the
width left by it, also on very wide screens.

Usage
=====

- Open a record whose chatter is on the side (large screens).
- Drag the left edge of the chatter (the right edge in right-to-left
  languages) to make it wider or narrower.
- Double-click the edge to restore the standard width.

The width is kept for the next records and views of the same kind, in
the same browser.
