This module adds a visual separator between each message of the chatter,
making it easier to distinguish where a message ends and the next one starts.

The native date separator is still displayed when the day changes. For the
messages of the same day, a lighter separator showing the message date and
time is displayed. Discuss channels and chat windows are not affected.
