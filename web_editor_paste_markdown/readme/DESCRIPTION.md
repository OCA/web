This module adds a **Paste Markdown** command to the command menu (type `/`) of the HTML
fields. The command opens a dialog where you paste Markdown text, see the HTML preview,
and insert the converted HTML into the field.

Tables, code blocks, inline code and quotes get inline styles, so that they render the
same way in the editor and in e-mails.

The conversion uses the Toast UI Editor library provided by
`web_widget_markdown_editor`.
