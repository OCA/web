Paste Markdown:

1. In any HTML field, type `/` and choose **Paste Markdown** (category "Basic blocks").
2. Paste the Markdown text on the left; the HTML preview is shown on the right.
3. Click **Insert HTML**: the converted content is inserted at the cursor.

To Markdown:

1. In any HTML field, type `/` and choose **To Markdown** for the whole field, or select
   some text and click the **To Markdown** button of the toolbar for the selection.
2. The dialog shows the content as Markdown on the left and its preview on the right.
3. Click **Copy** to put the Markdown in the clipboard. Images stored in Odoo get their
   full address; embedded (base64) images are replaced by their description.
4. Or edit the Markdown and click **Replace**: the selection, or the whole field, is
   replaced by the converted content. If the content had formatting that Markdown cannot
   express (colors, font sizes, merged cells), a warning asks you to confirm. Undo
   (Ctrl+Z) restores the previous content.
5. **Close** leaves the field unchanged.
