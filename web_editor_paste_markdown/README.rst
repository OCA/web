This module brings Markdown to the HTML fields, without storing
Markdown: the field keeps its HTML.

- **Paste Markdown** (command menu, type ``/``): a dialog where you
  paste Markdown text, see the HTML preview, and insert the converted
  HTML into the field.
- **To Markdown** (command menu for the whole field, toolbar button for
  the selected text): the same dialog, filled with the content converted
  to Markdown. Copy it to use it outside Odoo, or edit it and replace
  the content.

Tables, code blocks, inline code and quotes get inline styles, so that
they render the same way in the editor and in e-mails. Markdown task
lists become Odoo checklists, and back.

The conversions run in the browser with the markdown-it and Turndown
libraries, shipped with the module: it does not need a Markdown editor
widget.

Use Cases / Context
===================

Documents written in Markdown (specifications, notes, AI generated
reports) lose their structure when pasted as plain text into an HTML
field.

The reverse is also needed: getting the content of an HTML field back as
Markdown, to reuse it in a Markdown file, a repository or a conversation
with an AI.

Configuration
=============

No configuration is required.

Usage
=====

Paste Markdown:

1. In any HTML field, type ``/`` and choose **Paste Markdown** (category
   "Basic blocks").
2. Paste the Markdown text on the left; the HTML preview is shown on the
   right.
3. Click **Insert HTML**: the converted content is inserted at the
   cursor.

To Markdown:

1. In any HTML field, type ``/`` and choose **To Markdown** for the
   whole field, or select some text and click the **To Markdown** button
   of the toolbar for the selection.
2. The dialog shows the content as Markdown on the left and its preview
   on the right.
3. Click **Copy** to put the Markdown in the clipboard. Images stored in
   Odoo get their full address; embedded (base64) images are replaced by
   their description.
4. Or edit the Markdown and click **Replace**: the selection, or the
   whole field, is replaced by the converted content. If the content had
   formatting that Markdown cannot express (colors, font sizes, merged
   cells), a warning asks you to confirm. Undo (Ctrl+Z) restores the
   previous content.
5. **Close** leaves the field unchanged.

Development
===========

The module patches ``HtmlField.wysiwygOptions`` (powerbox commands) and
``HtmlField.startWysiwyg`` (toolbar button). The conversions are
exported functions of ``static/src/js/paste_markdown.esm.js``:

- ``markdownToHtml`` renders the Markdown with markdown-it, sanitizes it
  with DOMPurify when raw HTML is allowed, then adds inline styles and
  Odoo checklists (``makeHtmlOdooCompatible``). Without markdown-it, the
  text is inserted escaped in a paragraph.
- ``htmlToMarkdown`` simplifies the HTML of the editor
  (``normalizeOdooHtml``), then converts it with Turndown and the GFM
  rules of ``addGfmRules`` (tables, strikethrough, task lists, compact
  list markers). Without Turndown, the text is returned.

The libraries are in ``static/lib`` (markdown-it 15.0.3, Turndown
7.2.5), unchanged from their npm packages, without source maps.

Tests: QUnit suite ``web_editor_paste_markdown``, run by
``tests/test_js.py``.

Known issues / Roadmap
======================

- The conversion to Markdown drops what Markdown cannot express: colors,
  font sizes, alignment, underline, merged table cells, mentions.
- A round trip (HTML to Markdown to HTML) normalizes the layout: list
  markers, line breaks and table alignment may change.
- An image written as a data: address in the pasted Markdown stays
  embedded in the HTML field.
- Raw HTML in the pasted Markdown is kept only once sanitized by
  DOMPurify, which the Odoo editor loads; otherwise it is inserted as
  text.
