This module adds a **Paste Markdown** command to the command menu (type
``/``) of the HTML fields. The command opens a dialog where you paste
Markdown text, see the HTML preview, and insert the converted HTML into
the field.

Tables, code blocks, inline code and quotes get inline styles, so that
they render the same way in the editor and in e-mails.

The conversion uses the Toast UI Editor library provided by
``web_widget_markdown_editor``.

Use Cases / Context
===================

Documents written in Markdown (specifications, notes, AI generated
reports) lose their structure when pasted as plain text into an HTML
field.

Configuration
=============

No configuration is required.

Usage
=====

1. In any HTML field, type ``/`` and choose **Paste Markdown** (category
   "Basic blocks").
2. Paste the Markdown text on the left; the HTML preview is shown on the
   right.
3. Click **Insert HTML**: the converted content is inserted at the
   cursor.

Development
===========

The module patches ``HtmlField.wysiwygOptions`` to add the powerbox
command. The conversion is the exported function ``markdownToHtml`` of
``static/src/js/paste_markdown.esm.js``: it renders the Markdown with an
off-screen Toast UI viewer, then adds inline styles
(``makeHtmlOdooCompatible``). Without Toast UI, the text is inserted
escaped in a paragraph.

Tests: QUnit suite ``web_editor_paste_markdown``, run by
``tests/test_js.py``.

Known issues / Roadmap
======================

- The command converts Markdown to HTML only; there is no HTML to
  Markdown export.
