Open a saved record with a PDF or supported image attachment in a form that
includes an attachment preview container, such as an invoice or vendor bill.

On a browser viewport at least 1534 CSS pixels wide, the attachment preview
appears on the right side and the chatter appears below the form. On smaller
viewports, Odoo keeps its standard layout without an automatic side preview.

Forms without an attachment preview container, and records without a PDF or
supported image attachment, keep their standard layout. This module restores
Odoo's existing layout rules; it does not add preview containers to other forms.
