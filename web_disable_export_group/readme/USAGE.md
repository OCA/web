- Users in the *Direct Export (xlsx)* group can use the 'Export All'
  option from the list and kanban views, even without the standard
  export access.
- Users with the standard *Export* access (granted to Settings users)
  can use the export dialog, but not 'Export All' unless they are also
  in the *Direct Export (xlsx)* group.
- Admin users are in both groups by default.
