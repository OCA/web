Open a document holding the configured lines, e.g. a purchase order, and click
the trash icon at the end of a line. A dialog asks the configured question:
confirming removes the line as usual, cancelling leaves it untouched.

The confirmation is also asked when the line is removed with the keyboard, when
the x2many field is displayed as a kanban, and when the line is opened in a
dialog and removed from there.

Create rules sparingly. Asking for a confirmation on every list of the database
trains users to click *Delete* without reading, which defeats the purpose.
