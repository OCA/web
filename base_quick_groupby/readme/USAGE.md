1. Install the module.
2. Open a list (tree) view with groupable columns (e.g., Contacts).
3. In the header cell of a groupable column, click the small toggle button that appears to the right of the column label.
   - Clicking it will apply grouping by that field; clicking again removes grouping.
Notes:
- The button is not shown for relational fields (one2many / many2many) or non-stored computed fields.
- This module implements a single-level toggle (groupBy = [] or [field]).
