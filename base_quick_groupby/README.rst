Adds a compact, toggleable group-by button to groupable list/tree column
headers (Odoo 17).

**Table of contents**

.. contents::
   :local:

Installation
============

1. Place ``base_quick_groupby`` in your Odoo addons path.
2. Update Apps list and install the module.
3. If assets don't appear, update assets / restart Odoo and clear
   browser cache.

Usage
=====

1. Install the module.
2. Open a list (tree) view with groupable columns (e.g., Contacts).
3. In the header cell of a groupable column, click the small toggle
   button that appears to the right of the column label.

   - Clicking it will apply grouping by that field; clicking again
     removes grouping. Notes:

- The button is not shown for relational fields (one2many / many2many)
  or non-stored computed fields.
- This module implements a single-level toggle (groupBy = [] or
  [field]).
