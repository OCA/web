This module allows administrators to reorder top-level Odoo menus
automatically via the Settings interface.

Two algorithms are available:

* **By alphabetical order**: sorts all top-level menus alphabetically
  using a configurable language.
* **By custom label list**: lets you specify an ordered list of menu
  labels (one per line). Menus matching the list are placed first in
  the given order; remaining menus are sorted alphabetically and
  appended at the end.
