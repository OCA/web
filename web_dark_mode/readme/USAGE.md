Each user chooses an *Appearance* in their *Preferences*, next to the language and
the time zone:

- **Default**: the theme follows the device, light or dark as it is set, evening
  included. It is checked at every page load and as soon as the device switches.
- **Light** or **Dark**: a fixed theme, whatever the device.

Saving the Preferences reloads the page, so the new appearance applies at once.

The *Dark Mode* switch of the user menu stays: it sets a fixed theme (Light or
Dark), as a choice made by hand. To follow the device again, pick *Default* in the
Preferences.
