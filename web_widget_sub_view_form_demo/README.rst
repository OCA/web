Demo of ``web_widget_sub_view_form``.

A partner can be a teacher or a student (``kind``), each type having its
own detail model:

- ``partner.teacher``: subject, hire date
- ``partner.student``: level, enrollment date

The partner form shows this detail in a ``Details`` tab, through the
``sub_view_form`` widget fed by the computed ``detail_ref`` reference
field.

.. IMPORTANT::
   This is an alpha version, the data model and design can change at any time without warning.
   Only for development or testing purpose, do not use in production.
   `More details on development status <https://odoo-community.org/page/development-status>`_

Usage
=====

Open a partner, ``Details`` tab, choose a type: the matching detail is
created on save and shown below. Switching the type keeps the previous
detail.

Teacher: ``partner.teacher`` detail, with an editable One2many and
many2many tags.

|Teacher|

Student: ``partner.student`` detail, with Many2one, Datetime, Image and
Binary fields.

|Student|
