- Enter your value in omnibar search field
- Press and hold Shift key
- Select field with mouse or keyboard to perform search on

To search for an exact value, write it between double quotes (for example
`"John Smith"`). This does not apply to search fields with a `filter_domain`
in the search view (for example the name of a contact or a product): those
always use the domain of the view.
