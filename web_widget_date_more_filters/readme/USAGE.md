The new periods are added to the date filter of the search panel, next to the months, quarters and
years already offered:

- **Today**, **Yesterday**;
- **This week**, **Last week** — from Monday to Sunday;
- **Last 7 days**, **Last 30 days**, **Last 365 days** — windows of whole days ending on the current
  day, today included: "Last 7 days" covers today and the six days before.

A period does not need a year: selecting one does not select a year with it, and removing a year does
not remove it. Months and quarters are different: they always need a year, and one is selected for
them.

Once a period is compared ("Previous Period"), a window is compared with the window of the same
length just before it.

The periods are added for every user when the module is installed: there is nothing to configure.
