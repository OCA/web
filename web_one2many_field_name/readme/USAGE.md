- Activate developer mode.
- Open a form with a list One2many (often without a visible label, for example
  notebook pages).
- Hover a column header to open the field tooltip.
- Under **Field:** (for example `mix_percentage`) you will also see:

  - **One2many:** `bom_line_ids`

Click the value to copy it. This works with `web_field_tooltip_copy` if that
module is installed, and also without it.
