Replaces the solid purple main navbar of the backend with a light one,
separated from the page by a thin line. Menu entries use the regular text
colors and the brand color is kept for the name of the current app.

A strongly colored bar draws the eye away from the content on every screen.
A light navbar keeps the focus on the view below it, and is closer to what
most web applications use today.

Only the navbar variables of `web` are overridden, so the module is easy to
review, to combine with other modules and to uninstall.
